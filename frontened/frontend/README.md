## To Use This Website
1. open folder Cineforge folder in vscode
2. open new terminal
3. now run frontend server - react server
```
cd frontend
npm i
npm run dev 
```
4. open new terminal
5. run backend server - flask server
```
cd backend
python app.py
```

6. now open in browser - show server running (Means server is started properly)
```
http://127.0.0.1:5000/
```

7. now open in browser - show website
```
http://localhost:5173/ 
```
